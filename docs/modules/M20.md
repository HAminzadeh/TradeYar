# M20 — قفل معاملات واقعی / Live Execution Lock

## هدف / Purpose

تمام درخواست‌های ثبت سفارش واقعی با HTTP 423 رد می‌شوند

All real order submissions are rejected HTTP 423

## روش استفاده / Workflow

دکمه تست قفل فقط برای بررسی ایمنی است

Lock-test button verifies safety only

## مقدار پیش‌فرض / Defaults

LOCKED و DISABLED

LOCKED and DISABLED

## بازنشانی / Reset

دکمه بازنشانی در رابط v0.4 مقدارهای فرمِ همین ماژول را به پیش‌فرض برمی‌گرداند؛ سفارش‌ها، هشدارهای ثبت‌شده، سوابق تحقیق و پایگاه داده را حذف نمی‌کند. تغییرات مشترک سمت سرور در M03 فقط با درخواست تأیید و `PUT /api/preferences` بازنشانی می‌شوند.

Reset only affects screen inputs/settings; it never deletes journal, evidence or broker data. The legacy M03 server preference update needs explicit confirmation.

## محدودیت و ایمنی / Limits

تا زمانی که منبع واقعی، داده کافی و اعتبارسنجی زمانی برقرار نشده، خروجی آزمایشی مجوز ورود به معامله نیست. Real-money execution remains hard locked (HTTP 423). Synthetic observations are not a ten-year training dataset.

## خطاها / Errors

اگر Backend خاموش باشد، صفحه پیام HTTP/Network را نشان می‌دهد. ابتدا `/api/health` را بررسی کنید. اگر داده ناقص باشد نتیجه باید `NOT_READY` یا `WAITING_FOR_DATA` بماند، نه یک سیگنال ساختگی.
